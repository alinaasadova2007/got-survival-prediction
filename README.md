## Задача

| | |
|---|---|
| Данные | 1557 размеченных персонажей, 389 тестовых, 24 исходных признака |

## Результаты

Все модели оценивались на одной стратифицированной validation-выборке (20%).

| Модель | Train accuracy | Validation accuracy |
|---|---|---|
| Константный прогноз | - | 0.779 |
| Logistic Regression | - | 0.776 |
| Logistic Regression + StandardScaler | - | 0.772 |
| Random Forest (230 деревьев) | 0.963 | 0.805 |
| **Random Forest, `max_depth=15`** | 0.946 | **0.817** |

Финальная модель обучена на всех размеченных данных. Предсказание для теста сохраняется в `new_submission.csv`.

## Подход

### Feature engineering

| Признак | Преобразование | Зачем |
|---|---|---|
| `popularity` | `log10(popularity * 100 + 1)` | распределение сильно скошено вправо |
| `numDeadRelations` | бинарный `boolDeadRelations` | положительные значения редки; при наличии связей с умершими живы 43% персонажей, без них - 79% |
| `age` | `age_value` (пропуск = 0) и флаг `age_no_data` | возраст известен только у 18% персонажей, удаление строк уничтожило бы 80% данных |
| `culture` | 51 значение сведено в 12 региональных групп, one-hot | дубли вроде `Northmen` / `northmen` и много редких категорий; доля живых по группам от 28% (Old Nations) до 95% (Dorne) |

В тестовой выборке у двух персонажей диапазон годов рождения склеился в одно число (`dateOfBirth = 298299`, возраст -298001). Возраст восстановлен по закономерности из обучающей выборки: у живых `age + dateOfBirth` всегда равно 305, у умерших - году смерти, и в испорченных строках эта сумма сохранилась.

### Модели

- **Logistic Regression** не превзошла константный прогноз: из 69 умерших в validation модель нашла 16 и ошибочно отнесла к умершим 17 живых. Стандартизация признаков результат не улучшила.
- **Random Forest** нашёл 34 умерших из 69, но без ограничения глубины переобучился (0.963 на train против 0.805 на validation).
- **Подбор глубины** (`max_depth` 5, 8, 10, 15): малая глубина снижает переобучение, но приводит к недообучению. Лучший результат на validation при глубине 15. Эта модель находит 31 умершего из 69, то есть меньше, чем лес без ограничения, зато реже ошибается на живых (19 ошибок вместо 26).

## Что можно улучшить

- Гиперпараметры подбирались на той же validation-выборке, на которой считается итоговая метрика, поэтому 0.817 - оптимистичная оценка. Разница с лесом без ограничения глубины (0.805) - всего 4 персонажа из 312, а глубина 10 оказалась хуже глубины 8, то есть часть разницы - шум конкретного разбиения. Корректнее использовать кросс-валидацию и отдельную отложенную выборку.
- При дисбалансе классов стоит дополнительно смотреть F1 и ROC-AUC для класса "умер".
- Новые признаки (титул, дом персонажа) и градиентный бустинг.
